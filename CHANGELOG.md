# Changelog

## 1.4.0 — 2026-10-17

- Universal macOS application with native Intel (x86_64) and Apple Silicon (arm64) slices.
- macOS 14.0 minimum deployment target for both architectures.
- Architecture, macOS and version labels derived from the running application.
- Reproducible build scripts, app ZIP, DMG, source package and SHA-256 checksums.
- MIT license for original code, third-party attribution and public-release documentation.
- Public preview contains no personal wallpaper; source packaging uses an explicit allowlist.
- Apple Silicon runtime validation remains pending; cross-compilation does not substitute for device testing.
