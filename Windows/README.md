# Codex 外观 · Windows

本地壁纸与玻璃样式管理器。保留 macOS 版的配色、图片导入、缩放、位置、可见度与模糊控制，增加分区域玻璃效果和 Windows 托盘。无需编辑 CSS。

## 使用

打开 `dist/CodexWallpaper-win32-x64/CodexWallpaper.exe`。程序文件夹必须完整保留。

- **壁纸**：导入多张 PNG、JPEG、WebP，拖入文件，点缩略图切换；13 套配色、图片缩放、横向偏移与上下位置。
- **高级设置**：底色、玻璃色、正文色、辅助文字色、强调色；顶部菜单、左侧导航、会话列表、输入框、文件卡片分别控制底色浓度和模糊；圆角、高光、边框、阴影与文字阴影。
- “底色浓度”越低越透明，只改变面板背景，不改变文字透明度。
- 默认实时应用，可关闭后点击“应用更改”。壁纸与高级参数独立保存。
- 连接后预览改为 Codex 当前窗口实景截图，等比例显示；应用更改后自动刷新，也可手动刷新。截图只在本机内存中显示，不保存、不上传。未连接时才使用布局示意图。
- 关闭窗口后继续在托盘运行；双击托盘图标重新打开。托盘可以快速切换壁纸。
- **恢复原样**暂停主题；**退出并恢复**退出程序并清除本工具样式。意外崩溃后，通常约 20–22 秒移除主题，休眠或后台节流可能延迟。

## 连接说明

当前支持 Windows x64、Microsoft Store 安装的官方 Codex。通过本机 CDP 向主窗口添加临时样式，核对包路径、进程与监听地址。

优先连接已经开放主题通道的正常配置实例。Codex 没运行时，“连接 Codex”会启动官方程序并使用原配置。若普通客户端已在运行且未开放通道，会提示先从托盘完全退出后重试；不会杀进程、复制登录信息或打开独立配置实例。成功连接后，下次打开管理器会尝试恢复连接。

从官方图标冷启动不保证有主题通道；本工具不会修改官方图标、WindowsApps 或 app.asar，也不会后台重启客户端。主题通道随当前 Codex 进程退出而关闭。

启用新管理器时会接替本机之前安装的 `acheron-css` 旧加载脚本，防止两者反复覆盖。移除的是旧运行时样式；旧文件保留。

## 数据与默认壁纸

配置与导入图片副本位于 Electron 当前用户的 `Codex Wallpaper` 应用数据目录，通常为 `%APPDATA%\Codex Wallpaper`。原图不改写；导入图片最长边缩至 2560 像素，按 JPEG 保存。

本机默认黄泉图来自用户已有素材。`private-assets/` 已被 Git 忽略，不能视作项目开源资产。若从干净仓库构建，没有默认图片也能启动和导入；本地定制构建会包含该图。公开发布前应按图片授权处理素材。

## 开发

需要 Node.js 22.12 或以上。

```powershell
npm install
npm run setup
npm test
npm start
npm run package
```

集成测试需要一个已经开放本机主题通道的正常配置 Codex，会临时应用并恢复外观：

```powershell
node tests/integration.cjs
.\node_modules\electron\dist\electron.exe . --test-profile --ui-test
```

Windows 界面使用 Electron，配色与主题机制参考同仓库 macOS 版。滤镜是 CSS 玻璃质感，不包含物理折射引擎。界面示意预览和实际 Codex 布局比例不同；客户端更新后需重新验证选择器。
